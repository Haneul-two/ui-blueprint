# UI 설계도

블록을 골라 원하는 자리에 놓으며 대시보드, 웹사이트, 앱 화면을 설계해 보는 웹 도구입니다.

- 블록 48개(레이아웃, 데이터, 입력, 피드백, 콘텐츠, 모션, 기기 틀). 미리보기에서 탭·토글·모달·폼 검증 같은 동작을 실제로 해 볼 수 있습니다.
- 끌어 놓기, 8px 격자와 안내선, 크기 조절, 실행 취소, 레이어(숨김·잠금·순서), 테마 조절판(강조색·모서리·글꼴·간격·밝기).
- 설계는 브라우저에 자동 저장됩니다. 서버로 보내지 않습니다.
- 내보내기: PNG 이미지, 설계 파일(JSON), 보기 전용 공유 링크, AI에게 넘길 사양서(Markdown).

## 실행

```bash
npm install
npm run dev
```

배포용 파일은 `npm run build`로 `dist/`에 만들어집니다. 정적 호스팅 어디에나 올릴 수 있습니다.

### 실패 기록 (그때그때 적음)
- 사양서 점검(읽기 전용 검토자) 지적 12건: 키트 사본 범위·라이선스 위치 미정, 프레임 시간 기준 판정 불가, 블록 대비 측정법 없음, PNG 판정이 0바이트뿐, 공유 링크 한도 동작 없음, 보기 화면 배치 미정, BlockDef 미정의, 글자 효과 개수 모호, 디자인 토큰 미정, AI 사양서의 좌표 해석 미정, 겹침·아트보드 변경 규칙 없음, 접근성·움직임 줄이기 증거 수단 없음. 모두 사양서에 반영.
- 디자인 계획 점검: 처음 정한 종이색 `#f6f4ee`이 생성형 화면의 흔한 기본값(따뜻한 크림)이라 차가운 제도 용지 `#eef1f5`로 바꿈.
- `useReducer`의 리듀서 안에서 만든 새 블록 id를 dispatch 직후 읽으려 함. 리듀서는 렌더 때 돌아서 id가 비어 선택이 안 됨. id를 dispatch 전에 만들어 넘기도록 고침(코드 검토 중 발견).
- Git Bash에서 `node scripts/shoot.mjs "#/blocks"`처럼 `#/`로 시작하는 인자를 넘기면 MSYS가 `#C:/Program Files/Git/blocks`로 바꿔 엉뚱한 화면을 찍음. `MSYS_NO_PATHCONV=1`로 해결.
- 단위 테스트에서 발견: 블록 5개의 최소 크기가 8의 배수가 아님(36·140·260 등) → 격자 배수로 고침. 채팅 블록의 `element.scrollTo`가 jsdom에 없어 그리기 실패 → `scrollTop` 대입으로 바꿈(모든 브라우저에서 동작). 전체 블록 회귀 설계가 높이 6000을 넘어 검사기에 걸림(높이순 배치 후에도 7,368px) → `artboardMaxH` 8000으로 올림.
- e2e 1회차: 검사 스크립트가 축소된 아트보드의 블록 안 좌표(x 300)를 눌러 옆 블록을 누름 → 요소 자체를 누르도록 고침(검사 쪽 버그).
- e2e 대비 측정에서 발견(실제 화면 문제): 키트 아바타 이니셜(흰 글자, 2.4~3.2:1), 키트 성공·주의 배지 글자(4.27:1), 키트 터미널 제목(4.1:1), 다크에서 위험 버튼(옅은 빨강 + 흰 글자 2.77:1), 다크 견본에서 블록 바탕이 비어 밝은 페이지가 비침(1.1:1), 다크에서 휴대폰 화면이 밝게 그려짐(1.2:1) → 모두 고친 뒤 0건.
- 키트 토큰을 덮는 이 사이트 CSS는 레이어 밖이라 키트 다크 값까지 덮음(`--ss-canvas`를 다크에서도 밝게 덮을 뻔함) → 라이트 전용 값은 `:not([data-theme="dark"])`로 한정.
- 사양서에 이 PC 절대 경로가 들어 있어 공개물 금지어 검사에 4건 걸림 → 일반어로 바꿈.

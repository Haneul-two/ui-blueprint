### 바꾼 것
- 첫 화면: 남색 청사진 히어로(흐르는 격자, 떠다니는 빛, 스캔 빛, 커서 주변 격자 밝힘), 제목 "놓으면 화면이 됩니다." 한 줄, 기울어진 도면 위에 대시보드 뼈대가 그려지고 커서가 KPI를 끌어다 놓는 반복 연출. 움직임 줄이기에서는 모두 멈춘다.
- 시작 카드: 종류 고르기를 아이콘 위·이름 아래 타일로 바꿔 "데스크톱"이 두 줄로 깨지던 문제 해결, 예시 미리보기를 남색 도면에 선 그림으로(올리면 다시 그려짐), 도면 번호·치수 표기.
- 편집기: 도구줄 남색, 캔버스 청사진 선 격자, 아트보드 위 표제(이름·치수)와 재단 표시, 치수 글자 고정폭 글꼴. 블록 견본 머리 남색 띠.
- 글꼴: Pretendard·JetBrains Mono를 사이트에 함께 싣는다(외부 글꼴 서버 접속 없음).
- 종류 전환 재배치(`src/model/reflow.ts`): 좁은 화면은 꽉 찬 폭·반 폭으로 쌓고 사이드바는 맨 위 띠, 넓은 화면은 옆 막대를 옆에 두고 원래 줄 단위로 비율 배치하다 안 들어가면 줄을 나눠 고르게(4개 → 2+2) 채운다. 바꾼 뒤 안내 토스트, Ctrl+Z로 되돌림. 최대 높이(8000px) 안에 못 놓으면 바꾸지 않고 알린다.
- 블록이 자기 폭에 맞춰 배치를 바꾼다(`.ub-item`에 container-type, `@container`): 상단 메뉴·히어로·푸터·벤토·가격표, 글자 효과 크기 min(px, 12cqw).

- 휴대폰 폭 390·태블릿 834가 8의 배수가 아니라 본문 폭·오른쪽 한계가 격자를 벗어났다 → 격자 배수로 내림.
- 대시보드 예시 검색창 높이 44가 격자 배수가 아니었다 → 48.
- 가격표 최소 폭 480이 휴대폰(390)보다 넓어 원래부터 아트보드 밖으로 넘쳤다 → 최소 폭 320, 좁으면 요금제를 옆으로 넘겨 본다.
- 후기 카드가 상자보다 40px 넓게 그려졌다(원래부터 있던 문제). 키트 리셋 `all: revert`가 figure의 box-sizing을 content-box로 돌려 폭 100% + 안쪽 여백이 넘쳤다 → 블록(`bk-*`)을 border-box로 고정. 48개 블록 전부 데스크톱·태블릿·휴대폰에서 상자 넘침 0 확인.
